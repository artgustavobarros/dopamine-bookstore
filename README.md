## The Premise

Buying books releases dopamine; actually reading them requires time, focus, and emotional discipline. 

**Depois Eu Leio** ("*I'll Read It Later*") is a satirical bookstore and full-stack portfolio demonstration that celebrates this human contradiction. Users can browse real literature fetched live from the [Open Library](https://openlibrary.org/) catalog, filter by genre, build wishlists, fill a cart, and complete an imaginary checkout (via *"Pix de Mentirinha"* or fake credit cards). 

**Zero real money changes hands (R$ 0,00), and no physical parcels are shipped.** Instead, every action—from hoarding massive 1,000-page tomes to repeatedly postponing reading—is met with comic toasts, simulated courier tracking, reading backlog statistics, and biting psychological evaluations generated by Google Gemini.

---

## Key Features

- **Live Open Library Integration**: Fetches real Portuguese and English editions with language filtering, debounced query execution, and intelligent fallbacks.
- **Satirical Checkout & Delivery Simulation**: Interactive checkout simulating instant Pix QR codes, card payments, ViaCEP auto-address discovery, real-time stage progression (packaging, transit, delivery), and manual receipt confirmation.
- **AI Comic Roasts & Clinical Psychiatric Diagnosis**: Powered by Google Gemini (`gemini-flash-lite-latest` / `gemini-3.5-flash-lite`) via TanStack Start server functions, reacting with comic onomatopoeia to hoarding habits or generating multi-paragraph psychiatric reports diagnosing *tsundoku*.
- **Offline & Deterministic AI Fallback**: If the Gemini API key is unset or external rate limits hit, the system falls back instantly to a curated deterministic catalog without failing the UI.
- **Reading Backlog Insights**: A dedicated stats dashboard calculating unread pages, cumulative reading hours, and virtual money saved.
- **Bilingual Experience**: Instant toggle between Brazilian Portuguese (`pt-BR`) and English (`en-US`).
- **Neo-Brutalist Comic UI**: High-contrast borders, offset hard shadows, halftone dot patterns, custom badges, and responsive GSAP entrance animations.

## Performance Engineering

This project was built with intentional performance engineering to deliver high speed, zero layout shifts, and respectful network usage.

### 1. Network, API & Data Fetching

- **Open Library Fair Use & Rate-Limit Queue**: Open Library is a non-profit public API. To prevent HTTP 429 errors and respect fair use, requests pass through a serialized rate-limit slot queue (`waitForSearchSlot` in `src/lib/open-library.ts`) that enforces a minimum 1,100ms spacing between outbound search queries.
- **Payload Field Projection**: Queries explicitly request only needed fields (`fields: "key,title,author_name,first_publish_year,number_of_pages_median,subject,cover_i,editions..."`), discarding large JSON blocks (descriptions, full edition trees, borrow history) and reducing API payload size by over **70%**.
- **Query Debouncing (700ms)**: Catalog searches in `src/routes/index.tsx` debounce keystroke inputs by 700ms, eliminating redundant in-flight network requests while the user types.
- **Request Abort Controllers**: Dynamic queries bind `AbortSignal.timeout(12_000)` combined with React Query cancellation signals (`AbortSignal.any`) to instantly cancel obsolete network requests when users navigate away or modify filters.
- **Aggressive Client Caching**: Catalog queries and individual book lookups define `staleTime: 1 hour` and `gcTime: 1 hour` in TanStack Query, guaranteeing that revisited works load instantly from memory without network roundtrips.

### 2. Core Web Vitals, Layout Stability & Image Strategy

- **Zero Cumulative Layout Shift (CLS = 0)**: Book covers use an explicit `aspect-[3/4]` container with predefined `width` and `height` attributes on both standard cards (`200x300`) and detail views (`320x480`). Space is reserved in the DOM prior to image download.
- **Typographic Fallback Stage**: If an Open Library cover image takes time to load or does not exist, the component renders a comic typography fallback with halftone radial dots. When the image arrives, it overlays seamlessly without pushing adjacent elements.
- **Adaptive Image Resolution**: The storefront loads medium resolution covers (`-M.jpg`, ~20–40 KB) in catalog grids and loads high resolution covers (`-L.jpg`) only on the book detail route (`/books/$bookId`), preventing bandwidth waste.
- **Native Lazy Loading**: All below-the-fold catalog images carry `loading="lazy"` to defer loading until cards enter the viewport threshold.

### 3. Asset Optimization & Zero-Blocking Typography

- **Self-Hosted Variable Fonts via `@fontsource`**: Rather than linking to external Google Fonts CDNs (which introduces external DNS lookups, TLS negotiations, and render-blocking CSS), all typefaces are self-hosted via npm packages:
  - `@fontsource-variable/work-sans` (Variable font covering all body weights in a single optimized WOFF2 request)
  - `@fontsource/archivo-black` (Display headers)
  - `@fontsource/space-mono` (Data badges & pricing)
  - `@fontsource/bangers` (Comic onomatopoeia & accent badges)
- **Zero Runtime CSS Overhead**: Tailwind CSS v4 runs via `@tailwindcss/vite` directly inside the build pipeline, emitting minimal scoped atomic CSS without JavaScript runtime styling overhead.

### 4. Motion Physics & UI Thread Efficiency

- **Automatic Lifecycle Scoping**: All GSAP animations are initialized inside `useGSAP()` hooks with scoped root refs (`scope: hero`, `scope: route`), automatically cleaning up tweens, timelines, and event listeners on unmount.
- **Accessibility & Reduced Motion**: Animations are wrapped in `withMotion` using `gsap.matchMedia("(prefers-reduced-motion: no-preference)")`. Users who request reduced motion at the OS level skip transforms and transitions entirely.
- **Pointer-Fine Interaction Guard**: Dynamic mouse-following tilt on hero books checks `(hover: hover) and (pointer: fine)`. Mobile devices and touchscreens bypass pointer move listeners completely, saving battery and GPU cycles.
- **GC-Free Animation via `gsap.quickTo`**: Cursor-following physics utilize `gsap.quickTo` pipes rather than creating new tween objects on every frame, eliminating garbage collection pauses during high-frequency mouse tracking.
- **Clean Hardware Acceleration**: Tweens specify `clearProps: "opacity,visibility,transform"` upon completion to ensure no lingering `will-change` layers or sub-pixel text rendering artifacts remain in the DOM.

### 5. Full-Stack Serverless AI & Edge Caching

- **Server Functions (`createServerFn`)**: AI calls run server-side via TanStack Start, ensuring the Google Gemini API key is never exposed to the client bundle.
- **Server-Side In-Memory Cache**: Repeated actions (e.g. adding the same book or repeating a checkout event) hit `serverRoastCache` (in `src/lib/server/roast.ts`), delivering sub-millisecond responses without querying the LLM API.
- **Model Cascade & Fast Timeouts**: AI requests apply strict timeouts (2,500ms for comic toasts, 10,000ms for psychiatric diagnosis) and cascade from `gemini-flash-lite-latest` to `gemini-3.5-flash-lite`.
- **Deterministic Offline Fallback**: If models timeout, rate-limit, or lack an API key, the system immediately returns an evaluated satirical punchline from `src/lib/roasts.ts`, ensuring the user never experiences a broken or hanging UI.
- **Strict Structured JSON Schema**: Gemini requests enforce strict JSON mime types and schema validation (`Type.OBJECT`, `Type.STRING`), preventing hallucinated markdown wrappers or malformed outputs.

### 6. Client-Side State & Hydration Safety

- **SSR Memory Fallback (`safeStorage`)**: Zustand's persistent storage adapter detects missing `window.localStorage` (during SSR, Node execution, or private browsing restrictions) and transparently falls back to an in-memory Map, eliminating hydration crashes.
- **Selector-Driven Subscriptions**: Components subscribe strictly to individual state slices (`useStore(state => state.locale)`, `useStore(state => state.cartIds)`), preventing unnecessary re-renders of unrelated tree nodes when the cart or wishlist updates.
- **State Versioning & Snapshotting**: Cached book metadata is snapshotted into order and cart items so historical records remain immutable and readable even if remote Open Library data shifts.

## SEO & AI Discoverability (AEO / GEO)

The project implements a modern multi-layer discoverability strategy covering traditional search engines, social crawlers, and AI answer engines (Answer Engine Optimization / Generative Engine Optimization).

### 1. Semantic JSON-LD Structured Data

The root layout (`src/routes/__root.tsx`) injects a comprehensive `@graph` structured schema:
- **`WebSite` Schema**: Declares canonical identity, multi-language availability (`["pt-BR", "en"]`), and search attributes.
- **`BookStore` Schema**: Clarifies that the platform operates with simulated currency (`priceRange: "R$ 0,00"`), accepts `Simulated zero-cost checkout`, and explicitly identifies the domain as a portfolio demonstration rather than a commercial retailer.
- **`FAQPage` Schema**: Pre-answers critical questions in both Portuguese and English regarding whether the store is real, whether credit cards or Pix are charged, and where book metadata originates. This informs Google Rich Results and AI grounding models.

### 2. AI Crawler Permissions & Scraper Filtering

The `public/robots.txt` is structured to grant explicit access to legitimate search engines and emerging AI answer engines while blocking scrapers:
- **Allowed AI Agents**: `GPTBot`, `ChatGPT-User`, `PerplexityBot`, `ClaudeBot`, `anthropic-ai`, `Google-Extended`, and `Applebot-Extended`.
- **Blocked Training Scrapers**: `CCBot` (Common Crawl indiscriminate training scraper).
- **Discovery Pointers**: Points directly to `/sitemap.xml` and `/llms.txt`.

### 3. Machine-Readable Agent Context (`llms.txt` & `pricing.md`)

- **`/llms.txt` Standard**: Provides structured Markdown designed for LLM scrapers and agentic search engines. It explains the project architecture, canonical routes, and confirms the non-commercial nature of the store to eliminate hallucinated purchase recommendations in tools like Perplexity or ChatGPT Search.
- **`/pricing.md` Protocol**: A dedicated machine-readable pricing specification explicitly declaring zero monetary cost across all items.
- **`/sitemap.xml`**: Canonical XML sitemap providing priority and change frequency for all primary pages (`/`, `/wishlist`, `/orders`, `/stats`, `/cart`, `/account`).

### 4. Social Metadata & Canonical Routing

- Canonical URLs (`https://dopamine-bookstore.vercel.app/`) defined on the root route.
- Open Graph tags (`og:title`, `og:description`, `og:image`, `og:url`, `og:site_name`, `og:type: website`).
- Twitter Card tags (`summary_large_image`).
- Search directives: `robots: "index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1"`.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- [pnpm](https://pnpm.io/) (v9+)

### Installation & Development

```bash
# 1. Clone repository and install dependencies
git clone https://github.com/artgustavobarros/dopamine-bookstore.git
cd dopamine-bookstore
pnpm install

# 2. Start local development server (runs on http://localhost:3000)
pnpm run dev
```

### Environment Variables

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

| Variable | Required | Default | Purpose |
| :--- | :--- | :--- | :--- |
| `GEMINI_API_KEY` | Optional | `""` | Google Gemini API key for dynamic AI roasts and psychiatric reports. If omitted, the app smoothly uses the built-in deterministic catalog. |
| `GEMINI_MODEL` | Optional | `gemini-flash-lite-latest` | Preferred Gemini model name. |

### Verification & Quality Checks

Run the project verification commands:

```bash
# Type check routes and TypeScript code
pnpm run typecheck

# Check formatting and linting rules (Biome / Ultracite)
pnpm run check

# Automatically fix linting and formatting issues
pnpm run fix

# Build production application bundle (Nitro + Vite)
pnpm run build

# Run end-to-end browser tests with Playwright
pnpm run test:e2e
```

*Note*: If running Playwright for the first time, install Chromium using:
```bash
pnpm exec playwright install chromium
```
