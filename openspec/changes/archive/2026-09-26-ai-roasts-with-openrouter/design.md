## Context

"Depois Eu Leio" (*Dopamine Bookstore*) is a satirical web bookstore simulating the emotional dopamine hit of buying books without spending money or finishing reading them. The current implementation uses simple static toasts (`sonner`) on actions such as adding to cart or checking out. The user wants dynamic, acidic, stand-up roast style comedy generated by LLMs via OpenRouter's free models (`:free`), combining:
- **Option B (Milestone Moments)**: Triggering punchy AI roasts during key actions (cart crossing 3+ books, crossing 1,000 pages, opening checkout, order completion) with uppercase SFX tags (e.g. `[ALERTA!]`, `[TERAPIA JÁ]`).
- **Option C (Dedicated Diagnosis)**: A prominent "Diagnóstico do Leitor" (Reader's Roast / Fritada Literária) card on `/stats` analyzing cumulative pretend spending, genres, and page hoards.

Constraints:
- Must use OpenRouter free tier models (`openrouter/free` router or `:free` models) with zero operating cost.
- Free models introduce variable latency (800ms - 3.5s) and potential rate limits (~20 RPM).
- The user interface must remain snappy, resilient, and responsive regardless of external network or API state.

## Goals / Non-Goals

**Goals:**
- Provide hilarious, acidic, comedy-roast feedback reflecting user decisions and shopping habits in real-time.
- Protect secrets by executing OpenRouter calls strictly in TanStack Start server functions.
- Combine reactive milestone toasts (Option B) with an on-demand in-depth roast card on `/stats` (Option C).
- Implement a robust 2.5-second timeout and curated local fallback dictionary to ensure zero broken UI states or blank errors.
- Support bilingual prompts and outputs in Brazilian Portuguese (`pt`) and English (`en`).

**Non-Goals:**
- Calling the AI on every single atomic button click (e.g. adding 1st book or removing 1 item) to avoid rate limit exhaustion and latency degradation.
- Requiring paid OpenAI or Anthropic API keys.
- Building a conversational multi-turn chat assistant.

## Decisions

### 1. Server Function Execution via `createServerFn`
- **Choice**: Call OpenRouter inside a TanStack Start server function (`generateRoastFn` and `generateDiagnosisFn`).
- **Rationale**: Keeps `OPENROUTER_API_KEY` securely on the server; prevents browser CORS restrictions; allows uniform server-side timeouts, error catching, and fallbacks.
- **Alternatives Considered**:
  - *Client-side direct fetch*: Discarded because exposing API keys in client bundles is insecure, and CORS/network policies can interfere.

### 2. Model Selection: `openrouter/free` with Fallback Chain
- **Choice**: Default to `openrouter/free` (OpenRouter's meta-router that load-balances across active free models like Qwen 27B, Gemma 31B, Nemotron, etc.), with fallback to `qwen/qwen3.8-27b:free` or `google/gemma-4-31b-it:free`.
- **Rationale**: High availability without hardcoding a single free model that could become temporarily overloaded or decommissioned.

### 3. Roast Comedy Prompt Engineering (Fritada Literária)
- **Choice**: Instruct the LLM in a roast comedy master persona ("humor de fritada"), specifically targeting book hoarding (*tsundoku*), the vanity of buying 1,000-page classics to impress visitors, productivity delusion, and 12-installment payment jokes.
- **Output Schema**: Structured JSON `{ "tag": "ALERTA!", "roast": "Texto curto da piada." }`.
- **Rationale**: Guarantees consistent styling across the UI (bold tag + punchline) while preventing generic preachy responses from the LLM.

### 4. Hybrid Graceful Degradation & Timeout Strategy
- **Choice**: Impose a strict 2.5s abort controller on OpenRouter calls. If OpenRouter times out, throws, or returns 429, the server immediately returns a context-matched roast from a static curated library inspired by the original reference.
- **Rationale**: Preserves comic timing and prevents sluggish or failing UI.

## Risks / Trade-offs

- **[Free Model Cold Starts / Queues]** → 2.5s AbortController aborts promptly and yields local fallback roasts if the API stalls.
- **[Content Filtering False Positives]** → The system prompt frames the humor strictly as playful self-deprecating book-buyer satire (*tsundoku*), avoiding hate speech or prohibited topics to sail through safety filters.
- **[Rate Limits on Free Tier (~20 RPM)]** → Milestones (Option B) reduce total API calls by ~70% compared to per-click toasts, and cache the Diagnosis on `/stats` during the session.

## Migration Plan

1. Add environment variable configuration for `OPENROUTER_API_KEY` in `.env.example` and local `.env`.
2. Implement server roast utility and server functions in `src/lib/server/roast.ts`.
3. Add local curated fallback library in `src/lib/roast-fallbacks.ts`.
4. Connect milestone triggers in cart and checkout.
5. Build the "Diagnóstico do Leitor" component and wire into `src/routes/stats.tsx`.
